## Hi there 👋

I'm Phakin (Nine), a Robotics and Automation Engineering student at KMUTT's Institute of Field Robotics in Bangkok, Thailand.

### 🤖 About Me

I specialize in autonomous systems, control theory, and robotics software development. Currently maintaining a 3.93 GPA and recipient of the Petchra Pra Jom Klao Scholarship for Innovation.

- 🔭 Working on autonomous mobile robots and precision control systems
- 🌱 Currently learning advanced control algorithms (MPC, LQR) and AI/ML for robotics applications
- 💬 Ask me about ROS2, path planning, or embedded systems
- 😸 Fun fact: Cats are the best debugging companions
- 🤐 Developing something interesting for my thesis (details coming soon!)

### 💻 What I Do

**🚗 Autonomous Navigation**
- Path following algorithms (Pure Pursuit, Stanley, Combined)
- SLAM-based mapping and localization
- Sensor fusion with Extended Kalman Filters
- RTK GNSS integration for centimeter-level accuracy
- HD map processing with Lanelet2

**⚙️ Control Systems**
- PID and cascade control implementation
- Trajectory planning (trapezoidal, S-curve)
- State estimation with Kalman filtering
- Motor control for DC, BLDC, and servo systems

**🔧 Embedded Development**
- Microcontroller programming (STM32, Arduino, ESP32)
- Communication protocols (CAN Bus, MODBUS, UART, I2C)
- PCB design and circuit implementation
- Real-time system development
- Hardware-software integration

**📦 Robotics Software**
- ROS2 architecture and package development
- Docker containerization for robotics
- Computer vision for object detection
- Kinematic modeling and simulation
- Multi-robot coordination
